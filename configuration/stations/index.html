Stations¶

Qseek needs the location and the code of every station. Load them from StationXML or Pyrocko station YAML files:

Stations from StationXML
"stations": {
  "station_xmls": ["meta/stations.xml", "meta/temporary-network/"],
  "exclude_stations": ["GE.RUE.", "6A.STA*"]
}

station_xmls takes files and directories; Qseek loads all .xml files of a directory. Pyrocko station YAML files go into pyrocko_station_yamls. When the search starts, Qseek removes stations without waveform data.

  • Exclude stations with exclude_stations, as station codes. Partial codes and wildcards exclude whole networks or groups of stations.
  • Limit the network with max_distance in meters from the center of the stations, e.g. to ignore distant stations of a regional network.

Instrument responses

Magnitudes and ground motions are measured on restituted waveforms. They need the instrument responses from StationXML.

StationInventory
{
  "pyrocko_station_yamls": [],
  "station_xmls": [],
  "exclude_stations": [],
  "stations": [],
  "max_distance": null
}

StationInventory pydantic-model ¶

Bases: Model

The seismic stations used in the search.

Stations are loaded from StationXML or Pyrocko station YAML files. When the search starts, stations without waveform data are removed.

Fields:

  • pyrocko_station_yamls (list[FilePath])
  • station_xmls (list[FilePath | DirectoryPath])
  • exclude_stations (NSLRejectList)
  • stations (list[Station])
  • max_distance (PositiveFloat | None)

pyrocko_station_yamls pydantic-field ¶

pyrocko_station_yamls: list[FilePath]

List of Pyrocko station YAML files.

station_xmls pydantic-field ¶

station_xmls: list[FilePath | DirectoryPath]

List of StationXML files or directories containing StationXML (.xml) files.

exclude_stations pydantic-field ¶

exclude_stations: NSLRejectList

Stations to exclude from the search, as NSL codes, e.g. ["GE.RUE."].

stations pydantic-field ¶

stations: list[Station]

List of stations in the inventory.

max_distance pydantic-field ¶

max_distance: PositiveFloat | None = None

Maximum distance in meters from the centroid location to include stations for detection. If None, all stations are included.
