# Python API

Qseek is a Python package. Besides the `qseek` command, you can use it in your own scripts, e.g. to analyze the detections of a run, or extend it with your own modules.

- [Detections](detections.md): load and analyze the detections of a run.
- [Stations](stations.md): station locations and codes.
- [Module base classes](modules.md): the interfaces for your own modules.
- [Utilities](utils.md): helper types.

The configuration models, e.g. `Octree`, `Location` or `CakeTracer`, are documented on the [configuration pages](../../configuration/index.md), together with their JSON.
